## Как собран

- `docs/gen/build.sh` → проверка имён → `build_kt.js` (текст, таблицы, штампы; `docx-js`) → `postprocess.py` (рамка листа и блок-схемы).
- `docs/gen/verify_names.js`: **каждое имя из таблиц 3.1–3.3 сверяется с исходным кодом** (82 имени); расхождение останавливает сборку.
- Рамка (185×287 мм, отступы 20/5/5/5 мм), большой штамп (форма 2, на первом листе), малый штамп (форма 2а, на остальных), номер листа и общее число листов — полями Word. Блок-схемы по ГОСТ 19.701-90 — редактируемые фигуры Word (не картинки).
- Данные штампа: `docs/gen/config.js` — единственное место для шифра, ФИО и названия.
- Этот же каркас (рамки, штампы, блоки текста и таблиц) будет основой пояснительной записки в Ф7.
