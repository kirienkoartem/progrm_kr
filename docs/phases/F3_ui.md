# Ф3. Каркас интерфейса — итоги

> **Статус: ✅ выполнено (05.10.2026).** Проект `src/Integral.App` (C#, WinForms, .NET Framework 4.8).

## Что сделано

| Окно / элемент | Реализация |
|---|---|
| Главное окно (MDI) | `MainForm`: главное меню (Файл, Расчёт, Окно, Справка), панель инструментов (8 кнопок), строка состояния из трёх областей: подсказка · состояние расчёта · метод |
| Горячие клавиши | Ctrl+N/O/S/E, F5 (вычислить), F6 (график), F1 (справка) |
| Состояние команд | кнопки и пункты меню «Сохранить», «Экспорт», «Вычислить», «График», «Метод» недоступны, пока нет окна расчёта; окно «График» работает с породившим его расчётом |
| Окно «Расчёт» | `CalcForm`: группы «Функция и пределы», «Метод и точность», «Результат»; сводная таблица методов; таблица сходимости; предупреждения (нечётное n, недостигнутая точность, негладкая функция) |
| Проверка ввода | сообщение с подсказкой допустимого значения, курсор в ошибочном поле; при ошибке в формуле — на позиции ошибки |
| Окно «График» | `GraphForm` + `PlotPanel`: кривая, площадь под ней, границы отрезка, узлы разбиения (n ≤ 64), оси с «круглыми» делениями, автомасштаб |
| Справка | `HelpForm`: дерево из 8 разделов + текст (работа с программой, формула, методы, формат файла, ошибки, клавиши) |
| О программе | `AboutForm`: вуз, факультет, кафедра, группа, студент, тема, руководитель, год, описание |
| Файлы | открытие `*.txt` (UTF-8, при ошибке кодировки — Windows-1251), сохранение исходных данных, сообщения об ошибках файла с номером строки |
| Оформление | Tahoma 10 пт, высота полей 20 px, интервалы 5/8 px, белые поля на светло-сером фоне, подсказки; DPI-aware манифест; значки панели инструментов рисуются кодом в одном стиле (`IconFactory`) |

В ядро добавлено для интерфейса: `NumberParser`, `AxisScale`; `Integral.Core` теперь собирается под `netstandard2.0` и `net48`. Тестов 130.

## Как проверено

- Сборка `dotnet build -warnaserror`: 0 предупреждений.
- Приложение запускалось под Mono в виртуальном экране; проверены: открытие окон, расчёт функции из задания обоими методами с ε = 10⁻⁶, график, справка, «О программе», сообщение об ошибке в формуле, состояние кнопок.
- **Не проверено (нужен Windows):** вид на настоящем Tahoma, диалоги открытия/сохранения файлов, DPI-масштабирование. В Mono есть дефект — кнопки со шрифтом 10 пт показываются без текста; на Windows этого быть не должно, но это первое, что стоит посмотреть.

## Отложено на следующие фазы

- Экспорт отчёта в HTML — пункт меню и кнопка есть, пока показывают сообщение (Ф4).
- Окончательные иконки и стиль (Ф5); полное содержание справки (Ф5).
- Факультет, кафедра и должность руководителя в «О программе» — заглушки в `AppInfo.cs`, ждут данных от студента.

## Как запустить на Windows

1. Visual Studio 2022 с нагрузкой «Разработка классических приложений .NET».
2. Открыть `Integral.sln`, сделать проект `Integral.App` запускаемым, F5.
