# Ф4. Обработчики событий и HTML-отчёт — план и итоги

> **Статус: ✅ выполнено (05.10.2026)** в ветке `f4`. Итоги — в конце файла.

> Ветка `f4`. Снимок для КТ 19.10 (Ф1–Ф3) — ветка `kt/19.10`; `main` остаётся на Ф3 до решения Артёма.
> Закрывает этап 5 календарного плана «Код обработчиков событий» (КТ 02.11).

## Цель

1. **Вывод результатов в файл `*.html`** (требование варианта 7): один самодостаточный файл с исходными данными,
   результатами обоих методов, предупреждениями, графиком (встроенный SVG), таблицами сходимости и значений функции.
2. Довести обработчики событий: экспорт, устаревшие результаты, перетаскивание файлов, открытие отчёта в браузере.

## Решения

| ID | Решение | Почему |
|---|---|---|
| Р4-01 | `PlotModel` в ядре: выборка точек, диапазоны, деления осей, узлы. Его рисуют два «отрисовщика»: `PlotPanel` (окно, GDI+) и `SvgPlot` (HTML) | Один алгоритм — одинаковый график в окне и в отчёте; тестируется без окон |
| Р4-02 | Диапазон по оси y — по 2-му и 98-му процентилям, если функция «улетает» (полюс) | Иначе один выброс сжимает весь график в линию |
| Р4-03 | Отчёт — HTML5 с встроенным CSS и SVG, кодировка UTF-8, числа с десятичной запятой, погрешности в виде m·10ⁿ | Открывается в любом браузере, печатается, не требует внешних файлов |
| Р4-04 | После сохранения отчёт открывается в браузере (как в примере КР) | Сразу видно результат |
| Р4-05 | Изменение исходных данных после расчёта помечает результаты как устаревшие; экспорт и график в этом случае предлагают пересчитать | Отчёт не должен расходиться с полями формы |
| Р4-06 | Перетаскивание `*.txt` в главное окно открывает файл | Удобство; обычная функция MDI-программ |

## Модули

| Файл | Назначение |
|---|---|
| `Integral.Core/PlotModel.cs` | данные графика: точки, диапазоны, деления, узлы |
| `Integral.Core/SvgPlot.cs` | график в SVG |
| `Integral.Core/HtmlReport.cs` | сборка HTML-отчёта |
| `Integral.Core/HtmlFormat.cs` | форматирование чисел и экранирование для HTML |
| `Integral.App/PlotPanel.cs` | переписан на `PlotModel` |
| `Integral.App/MainForm.Files.cs` | экспорт, открытие в браузере, перетаскивание |
| `Integral.App/CalcForm*.cs` | снимок данных расчёта, устаревшие результаты |
| `Integral.Cli` | ключ `--html файл.html` |

## Проверка

- Модульные тесты: `PlotModel` (диапазоны, разрывы, узлы, выбросы), `SvgPlot` (корректный XML), `HtmlReport` (все разделы, экранирование, формат чисел).
- Отчёт для функции из задания открывается в Chromium (снимок экрана) — проверка вёрстки глазами.
- Окна — под Mono; финальная проверка экспорта и браузера — у Артёма на Windows.

## Итоги

- **HTML-отчёт**: шапка с формулой и пределами, карточки со значениями интеграла, предупреждения, исходные данные, таблица результатов,
  график (SVG), таблицы сходимости, значения функции в 21 точке. Один файл, UTF-8, без внешних ресурсов; печатается из браузера.
- **Экспорт из программы**: Ctrl+E / кнопка панели → диалог сохранения (имя по умолчанию «Отчёт - <окно>.html») → файл → открытие в браузере.
  Если браузер открыть не удалось — сообщение с путём к файлу.
- **Устаревшие результаты**: изменение любого поля после расчёта → предупреждение в окне и строке состояния; экспорт и график спрашивают
  «Пересчитать? Да / Нет / Отмена».
- **Перетаскивание** `*.txt` из Проводника в главное окно открывает файл в новом окне расчёта.
- `PlotModel` — общая модель графика для окна и отчёта; `PlotPanel` переписан на неё. Полюс функции больше не сжимает график в линию.
- Консоль: `integ_cli <файл.txt> --html отчёт.html`.
- Справка: новый раздел «Отчёт в HTML», упоминание перетаскивания.
- Тестов 142 (новые: модель графика, SVG, форматирование, отчёт). Сборка без предупреждений, файлы ≤ 250 строк.

### Как проверено

- Отчёты для функции из задания (оба метода, ε = 10⁻⁶) и для 4/(1+x²) (трапеции, n = 8, видны узлы) открыты в Chromium; вёрстка проверена глазами,
  исправлены ширина таблицы результатов и выравнивание таблицы значений.
- Под Mono: экспорт через диалог создал файл; сценарий «изменил формулу → F6 → Да» пересчитал и построил новый график.
- **Попутно найдена ошибка Ф3**: значок `app.ico` целиком из PNG-кадров не загружался в Mono и мог не загрузиться в .NET Framework.
  Исправлено (кадры до 128 px — BMP) отдельным коммитом и перенесено в ветки `kt/19.10` и `main`.

### Не проверено (нужен Windows)

- Открытие отчёта в браузере по умолчанию, перетаскивание из Проводника, внешний вид диалогов.
