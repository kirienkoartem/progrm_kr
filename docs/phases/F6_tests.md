## Находки при составлении примера

- В файле исходных данных пределы `a` и `b` принимаются только **числами**; `pi` и `e` работают лишь в формуле.
  Это решение Ф1; в методичке и задании ничего об этом нет. Менять не стал (не требование), оставил отмеченным в тесте.
- Ошибка внутри формулы из файла приходит под кодом `FileBadFormula` с номером строки, исходный текст ошибки вложен.
- Функция из задания при ε = 10⁻⁶ даёт расхождение с эталоном ≈ 1,5·10⁻⁶ (трапеции) и ≈ 4,7·10⁻⁶ (Симпсон) — это негладкость √x
  (см. Ф1), поэтому допуск для неё 10⁻⁴, а не 10⁻⁷.

## Чек-лист для Windows (10 минут)

1. Файл → Открыть… → `ok07_task.txt` → F5 → скриншот окна расчёта; Ctrl+E → открыть HTML в браузере → скриншот.
2. Открыть `ok10_simpson_odd.txt` → в окне должно быть «n увеличено до чётного».
3. Открыть `err01_paren.txt`, `err05_div_zero.txt`, `err07_empty.txt` → скриншот сообщения об ошибке каждого.
4. Перетащить `ok01_x2.txt` из Проводника в окно программы → файл открывается.
