# purpose | Назначение программы
Программа «Интегрирование функций» вычисляет определённый интеграл функции одной переменной, заданной формулой, на отрезке [a; b].

Для вычисления используются два метода численного интегрирования: метод трапеций и метод Симпсона. Можно рассчитать интеграл одним методом или обоими сразу и сравнить результаты.

## Что умеет программа
- читать исходные данные из текстового файла *.txt или принимать их в окне;
- вычислять интеграл при заданном числе разбиений n или подбирать n автоматически под заданную точность ε;
- оценивать погрешность по правилу Рунге и предупреждать, если функция негладкая и оценка ненадёжна;
- показывать график функции и площадь под ним;
- сохранять отчёт о расчёте в файл HTML.

Интерфейс многооконный: можно открыть несколько расчётов одновременно и переключаться между ними.

# start | Начало работы
1. Выберите «Файл — Новый расчёт» (Ctrl+N). Откроется окно «Расчёт».
2. В группе «Функция и пределы» введите формулу f(x) и пределы a и b.
3. В группе «Метод и точность» выберите метод и число разбиений n. Если нужна заданная точность, введите ε, например 1e-6.
4. Нажмите «Вычислить» (F5 или Enter). Результаты появятся в таблицах окна.
5. Чтобы увидеть график, выберите «Расчёт — Показать график» (F6).
6. Чтобы сохранить отчёт, выберите «Файл — Экспорт отчёта в HTML» (Ctrl+E). Отчёт откроется в браузере.

## Готовые данные
Вместо ручного ввода можно открыть файл исходных данных: «Файл — Открыть данные» (Ctrl+O) или перетащить файл *.txt из Проводника в окно программы. Каждый файл открывается в отдельном окне «Расчёт».

Введённые данные можно сохранить в файл: «Файл — Сохранить данные» (Ctrl+S).

# windows | Окна программы
## Главное окно
- Главное меню: «Файл», «Расчёт», «Окно», «Справка».
- Панель инструментов: новый расчёт, открыть, сохранить, экспорт в HTML, вычислить, график, справка, о программе. Недоступные в данный момент кнопки затемнены.
- Строка состояния: слева — подсказка к элементу под указателем мыши, в середине — состояние последнего расчёта, справа — выбранный метод.

## Окно «Расчёт»
- «Функция и пределы»: формула f(x), пределы a и b.
- «Метод и точность»: метод (трапеций, Симпсона, оба), число разбиений n, точность ε, кнопка «Вычислить».
- «Результат»: сводная таблица (значение интеграла, n, шаг h, оценка погрешности, фактический порядок сходимости, число вычислений f(x), время), предупреждения и таблица сходимости выбранного в сводной таблице метода.

## Окно «График»
Кривая f(x) и закрашенная площадь на отрезке [a; b]. Подробнее — в разделе «График».

## Несколько окон
Меню «Окно» располагает окна каскадом или мозаикой, закрывает все окна и содержит список открытых окон для быстрого перехода. Ctrl+Tab — следующее окно, Ctrl+F4 — закрыть окно.

# formula | Запись формулы
Формула записывается как в математике, но с явными знаками операций.

## Допустимые элементы
- числа: 2, 0,5, 1.5, 2,5E-3 (дробная часть — через точку или запятую, порядок — через E);
- переменная x;
- константы pi (число π) и e (основание натурального логарифма);
- знаки операций: + − * / и ^ (степень);
- круглые скобки для изменения порядка действий.

## Функции
- sin, cos, tg, ctg — тригонометрические функции (аргумент в радианах);
- arcsin, arccos, arctg — обратные тригонометрические функции;
- exp — экспонента, ln — натуральный логарифм, lg — десятичный логарифм;
- sqrt — квадратный корень, abs — модуль.

Аргумент функции пишется в скобках: sin(x), sqrt(x+1).

## Правила
- Знак умножения пишется всегда: 2*x, а не 2x.
- Степень вычисляется справа налево: 2^3^2 = 2^9 = 512.
- Унарный минус слабее степени: -x^2 = -(x^2).
- Регистр букв не важен: SIN(X) = sin(x).

## Примеры
    20*sin(sqrt(x)*3)
    4/(1+x^2)
    exp(-x^2)
    x^3 - 2*x + 1

# methods | Методы и точность
Отрезок [a; b] делится на n равных частей с шагом h = (b − a) / n.

## Метод трапеций
I ≈ h · [ (f0 + fn) / 2 + f1 + f2 + … + fn−1 ]. Порядок точности 2: при удвоении n погрешность уменьшается примерно в 4 раза.

## Метод Симпсона
I ≈ h/3 · [ f0 + 4·(f1 + f3 + …) + 2·(f2 + f4 + …) + fn ], n — чётное. Порядок точности 4: при удвоении n погрешность уменьшается примерно в 16 раз. Метод точен для многочленов до третьей степени. Если введено нечётное n, программа увеличит его на 1 и сообщит об этом.

## Оценка погрешности
Погрешность оценивается по правилу Рунге: R = |I(2n) − I(n)| / (2^p − 1), где p = 2 для трапеций и p = 4 для Симпсона.

- Поле ε пустое — расчёт выполняется при заданном n, оценка погрешности выводится в таблице.
- Поле ε заполнено — n удваивается, пока оценка больше ε (но не более 1 048 576). Все шаги показаны в таблице сходимости.

## Негладкие функции
Если у функции в точке отрезка бесконечная производная (например, sqrt(x) у нуля), фактический порядок сходимости ниже теоретического и оценка по правилу Рунге занижена. Программа определяет фактический порядок по последним удвоениям и выводит предупреждение. В таком случае задавайте ε с запасом.

# file | Формат файла исходных данных
Файл *.txt состоит из строк вида «ключ = значение». Всё, что стоит после символа #, — комментарий. Пустые строки пропускаются, регистр ключей не важен.

## Ключи
- function — формула подынтегральной функции (обязательно);
- a, b — нижний и верхний пределы (обязательно);
- method — trapezoid, simpson или both (можно по-русски: трапеции, симпсон, оба); по умолчанию simpson;
- n — число разбиений, по умолчанию 100;
- eps — требуемая точность (необязательно).

## Пример
    # интеграл функции из задания
    function = 20*sin(sqrt(x)*3)
    a = 0
    b = 10
    method = both
    n = 100
    eps = 1e-6

Файл можно сохранить в кодировке UTF-8 или Windows-1251. При ошибке программа укажет номер строки.

# graph | График
Окно «График» открывается командой «Расчёт — Показать график» (F6) для активного расчёта.

- Тёмная линия — график f(x).
- Закрашенная область — площадь под графиком на отрезке [a; b]; выше оси x она учитывается со знаком «+», ниже — со знаком «−».
- Пунктир — границы отрезка a и b.
- При n не более 64 показаны узлы разбиения; для метода трапеций они соединены ломаной — видно, какую фигуру на самом деле измеряет метод.

Масштаб подбирается автоматически и меняется вместе с размером окна. Если функция в какой-то точке не определена, линия в этом месте прерывается. В заголовке окна указано значение интеграла.

# report | Отчёт в HTML
Команда «Файл — Экспорт отчёта в HTML» (Ctrl+E) сохраняет результаты активного расчёта в веб-страницу и открывает её в браузере.

## Содержание отчёта
- формула, пределы и значения интеграла каждым методом;
- исходные данные и таблица результатов;
- предупреждения (нечётное n, недостигнутая точность, негладкая функция);
- график функции с закрашенной площадью;
- таблицы сходимости и значения функции в 21 точке отрезка.

Отчёт — один файл без внешних ресурсов: его можно отправить, открыть на другом компьютере и распечатать из браузера.

Если после расчёта исходные данные были изменены, программа предложит пересчитать их перед экспортом.

# errors | Сообщения об ошибках
## Ошибки в формуле
Указывается позиция символа, курсор ставится в это место поля.
- «Ожидается ")" в позиции N» — не закрыта скобка.
- «Неизвестное имя "…"» — опечатка в имени функции, например sn вместо sin.
- «Недопустимая лексема в позиции N» — пропущен знак операции, например 2x вместо 2*x.
- «Недопустимый символ» — в формуле есть символ, которого нет в списке допустимых.

## Ошибки вычисления
Указывается значение x, при котором функция не определена:
- деление на ноль;
- логарифм неположительного числа, корень из отрицательного числа;
- арксинус или арккосинус вне отрезка [−1; 1];
- тангенс или котангенс в точке разрыва;
- степень отрицательного числа с нецелым показателем.

Измените пределы так, чтобы функция была определена на всём отрезке.

## Ошибки в полях и файлах
- Ошибка в числовом поле: курсор переходит в поле, сообщение подсказывает допустимое значение.
- Ошибка в файле исходных данных: указывается номер строки.
