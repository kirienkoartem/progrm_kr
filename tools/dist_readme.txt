СОДЕРЖИМОЕ ДИСКА
  Программа\               готовая программа: Integral.exe (+ Integral.Core.dll, Integral.exe.config)
  Примеры данных\          файлы исходных данных *.txt для проверки программы
  Исходный код\            файлы проекта (решение Visual Studio Integral.sln)
  Пояснительная записка\   пояснительная записка в формате Word (.docx)

ЗАПУСК
  1. Скопируйте папку «Программа» на компьютер (или запустите прямо с диска).
  2. Запустите Integral.exe.
  Требуется Windows 10/11 (на них .NET Framework 4.8 уже установлен) или Windows 7/8.1 с установленным .NET Framework 4.8.
  Файлы Integral.exe, Integral.Core.dll и Integral.exe.config должны лежать в одной папке.

ПРОВЕРКА
  Файл - Открыть данные (Ctrl+O) - выбрать файл из папки «Примеры данных» - Расчёт - Вычислить (F5).
  Файл исходных данных можно также перетащить мышью в окно программы.
  Справка по работе с программой: клавиша F1 или меню «Справка - Содержание».

СБОРКА ИЗ ИСХОДНОГО КОДА
  Visual Studio 2022 (нагрузка «Разработка классических приложений .NET»):
  открыть Исходный код\Integral.sln, назначить проект Integral.App запускаемым, нажать F5.
  Без Visual Studio (нужен .NET SDK): запустить Исходный код\build.bat.
  Проект Integral.Tests содержит автоматические тесты вычислительного ядра (Тест - Запустить все тесты).
